# Accessibility review checklist

Use this checklist during manual testing. It is not a claim of a completed automated WCAG certification.

- [ ] Navigate every page using only Tab, Shift+Tab, Enter, Space, and Escape.
- [ ] Confirm the skip link appears on keyboard focus and moves focus to main content.
- [ ] Confirm focus indicators remain visible.
- [ ] Check that each form input has a visible label.
- [ ] Submit the form empty and confirm errors are announced and focus moves to the first invalid field.
- [ ] Enter a valid name, email, and message and confirm success feedback.
- [ ] Open and close the dialog with keyboard and confirm focus returns to the open button.
- [ ] Check table caption and header relationships with a screen reader if available.
- [ ] Zoom to 200% and test at a narrow mobile viewport.
- [ ] Test with a screen reader such as TalkBack, NVDA, or VoiceOver.
